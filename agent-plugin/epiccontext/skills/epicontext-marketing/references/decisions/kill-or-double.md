# Decision — Kill a channel vs double down

**The decision:** a channel is underperforming — do you kill it or invest more?

**Why it's hard:** marketing has lag (1–4 weeks minimum to see whether a channel works), and mental availability compounds slowly. Killing on one bad week destroys a link you were building.

**How to decide:**
1. **Give it a fair window** — judge over a full cycle, never one week. Has it had enough cadence to build any memory link?
2. **Check the persona/CEP fit** — is it underperforming because it's the wrong channel for the persona, or because execution/cadence was thin? Wrong-fit → kill; thin-execution → fix before judging.
3. **Read CAC trend, not absolute** — improving CAC over cycles → double down; flat/worsening at a believable spend → kill.
4. **Incrementality** — for paid, is the spend actually incremental, or cannibalizing organic? (See `epicontext-search-optimization` on branded-paid iROAS.) Non-incremental → cut regardless of surface metrics.

**Trade-off:** doubling down concentrates risk; killing forfeits the memory link already built. State which you're accepting.

**Reversal condition:** re-open a killed channel if the persona's behaviour shifts there, or a priority CEP becomes under-served.
