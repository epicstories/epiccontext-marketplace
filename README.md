# Epic Context plugin marketplace

Generated from the epiccontext repository by CI — do not edit here.

Claude Code 2 or newer, in a terminal: `claude plugin marketplace add https://github.com/epicstories/epiccontext-marketplace.git`, then `claude plugin install epiccontext@epiccontext`. It is public: no GitHub account is needed. Updates: `claude plugin marketplace update epiccontext`, then `claude plugin update epiccontext@epiccontext` (or turn on auto-update in `/plugin` → Marketplaces).
If adding says its source doesn't match: the marketplace is on the machine already. Run `claude plugin marketplace update epiccontext` and go on with the install.
The steps, with the connector and git access: https://www.epiccontext.com/docs/connect/plugin
Agent Plugins 1.0 (ChatGPT, Codex, Cursor, Copilot): `agent-plugin/epiccontext/`.
