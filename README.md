# Epic Context plugin marketplace

Generated from the epiccontext repository by CI — do not edit here.

Claude Code 2 or newer, in a terminal: `claude plugin marketplace add epicstories/epiccontext-marketplace`, then `claude plugin install epiccontext@epiccontext`. Updates: `claude plugin marketplace update epiccontext`, then `claude plugin update epiccontext@epiccontext` (or turn on auto-update in `/plugin` → Marketplaces).
If adding says its source doesn't match: the marketplace is on the machine already, added by its git address. Update it, or add it with `claude plugin marketplace add https://github.com/epicstories/epiccontext-marketplace.git`.
The steps, with the connector and git access: https://www.epiccontext.com/docs/connect/plugin
