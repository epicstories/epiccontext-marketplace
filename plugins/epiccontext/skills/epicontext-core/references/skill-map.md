# Which skill for what

The quick reference that used to sit in the core SKILL.md. Load the skill that matches the work; `epicontext-core` is always relevant.

| Working on… | Skill |
|---|---|
| A brand-new project — "what do I do now?" | `epicontext-kickoff` |
| Fill / populate the whole graph | `epicontext-fill` |
| Brand voice, positioning, vision, messaging | `epicontext-brand` |
| Product strategy, business model, OGSM, roadmap, business case | `epicontext-business-strategy` |
| Personas, JTBD, journeys, insights, competitors, research | `epicontext-users` |
| Features, glossary, IA, content, product overview | `epicontext-product` |
| Design system, tech stack, ADRs, architecture, infra, legal | `epicontext-build` |
| Running cost, cloud bill, model spend, budgets | `epicontext-finance` |
| Marketing strategy, campaigns, channels, content pieces | `epicontext-marketing` |
| SEO, SEA, GEO/AEO — search and AI-answer visibility | `epicontext-search-optimization` |
| KPIs, analytics, feedback | `epicontext-performance` |
| Project rules, glossary terms, section guides | `epicontext-constitution` |
| Cross-group reasoning, diagnoses | `epicontext-analysis` |
| Connection rules between blocks | `epicontext-connections` |
| Audit / link integrity + repair / project health | `epicontext-alignment` |
| Designing screens and variants on the design canvas | `epicontext-design` |
| Workshops on Miro / FigJam boards | `epicontext-boards` |
| Choosing or reviewing a frontend framework | `epicontext-framework-selection` |
| Building UI (any stack) | `epicontext-frontend` |
| Building APIs / DB / server code | `epicontext-backend` |
| Planning stories + sprints | `epicontext-development` |
