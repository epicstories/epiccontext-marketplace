# Decision Tree: Messaging Hierarchy

Deciding what's primary, what's supporting, what's not said. Messaging discipline through hierarchy.

## Start here

**For each candidate message, ask:**

```
├─ Is this the most distinctive thing about us in our competitive frame?
│   → Primary candidate
│
├─ Does this support or substantiate the primary?
│   → Supporting message
│
├─ Does this address an audience-specific concern not covered by primary?
│   → Audience-adapted supporting message
│
├─ Does this just describe a feature without strategic relevance?
│   → Probably not message-level — surfaces in feature copy
│
└─ Does this contradict or dilute the primary?
    → Cut. Or revise primary if this is more important.
```

## Identifying the primary

**Test 1: Distinctiveness.** Could a competitor say this? If yes, it's category messaging, not your messaging.

**Test 2: Customer language.** Do customers actually say this when describing their problem? If your primary uses words customers don't use, you have a translation gap.

**Test 3: Evidence.** Is there research, customer signal, or operational reality backing this primary message?

**Test 4: Endurance.** Will this still be primary in 12 months? Primary messages should be stable; supporting messages can rotate.

## Supporting message structure

Each supporting message should:
- Substantiate the primary (provide proof, evidence, specificity)
- Address a barrier or concern that primary alone doesn't
- Be specific enough to be testable

**Examples of good supporting messages:**
- "Trusted by [N] regulars since [year]" (social proof, supports primary)
- "Pricing shown upfront — no upsells" (addresses anxiety force, supports primary)
- "Booking takes under 90 seconds on mobile" (addresses friction, supports primary)

**Examples of weak supporting messages:**
- "Friendly therapists" (vague, not distinctive)
- "Modern booking system" (says nothing specific)
- "Quality you can trust" (empty phrase)

## Audience-adapted messaging

The same brand can lead with different messages for different audiences:

**For first-time customers:** Quality and trust matter most. Lead with consistency and credentials.

**For returning customers:** The relationship matters most. Lead with the named therapist they're rebooking.

**For gift purchasers:** Recipient flexibility matters most. Lead with redemption ease.

**For B2B vs. B2C:** B2B leads with ROI and integration; B2C leads with experience and outcome.

The primary brand message stays stable; the surface emphasis adapts.

## What to NOT say

A messaging document should include a "what we don't say" section. Examples we deliberately avoid:

- "Industry-leading" — superlative without substance
- "Bespoke / tailored" — overused, often inaccurate
- "Holistic" — too vague to be useful
- "Cutting-edge" — usually not, and customers don't care

This list is brand discipline through exclusion. Without it, drift creeps.

## Common failure modes

- **Too many primaries** — trying to lead with 5 things means leading with nothing
- **Primary that's actually a feature** — features describe what; messages describe why-it-matters
- **Supporting messages that don't support** — list of unrelated claims, not coherent hierarchy
- **No audience adaptation** — same primary for everyone when JTBDs differ
- **No exclusion list** — discipline through addition only; eventually everything is said
- **Stale messaging** — written 18 months ago, never refreshed as positioning evolved

## Quick guide

| Question | Answer location |
|----------|----------------|
| The single most distinctive claim | Primary |
| Proof, evidence, specificity for primary | Supporting |
| Audience-specific concerns | Audience-adapted |
| Feature description | Feature copy, not messaging |
| Common phrase we deliberately avoid | What-we-don't-say list |
